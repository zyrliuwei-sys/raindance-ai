# Raindance AI 品牌视觉规范: Afterglow (余晖)

> 定位：一张人像照片生成 5 秒海边栈桥黄金时刻竖屏短片。
> 设计判断：面向社媒创作者的高级消费级工具，电影感 + 杂志感，克制而温暖。
> 一句话方向：**蓝调时刻的墨色做底，黄金时刻的光做重点。**

## 1. 色彩

整站只用深色模式（`:root` 与 `.dark` 共用同一套值，见 `src/styles/globals.css`）。

| Token           | oklch             | 约等于  | 用途                                   |
| --------------- | ----------------- | ------- | -------------------------------------- |
| `--tide`        | `0.17 0.024 262`  | #0f1524 | 页面背景（日落后的海）                 |
| `--tide-raised` | `0.205 0.026 262` | #161d2e | 卡片、表单面板                         |
| `--tide-deep`   | `0.135 0.02 262`  | #0a0e19 | 交替区块、页脚、侧边栏                 |
| `--salt`        | `0.955 0.014 82`  | #f6efe2 | 正文与标题                             |
| `--haze`        | `0.74 0.024 255`  | #a3abbb | 次要文字                               |
| `--sun`         | `0.83 0.118 72`   | #f2bc69 | 主色：按钮、链接、播放头、强调         |
| `--sun-soft`    | `0.89 0.08 78`    | #f7d49a | 主色悬停态                             |
| `--ember`       | `0.7 0.125 36`    | #e37f5c | 余晖珊瑚色，只用于太阳渐变和 Logo 倒影 |
| `--line`        | `0.31 0.026 262`  | #2f3648 | 分隔线、边框                           |

规则：

- 一屏内只有一个琥珀色主行动点；`--ember` 不用于按钮或文字。
- 不使用纯黑、纯白、紫色、霓虹发光、渐变文字。

## 2. 字体

| 角色 | 字体                                        | 用法                                   |
| ---- | ------------------------------------------- | -------------------------------------- |
| 展示 | Cormorant Garamond（斜体 500）              | H1/H2/H3、Wordmark、价格数字           |
| 正文 | Manrope                                     | 正文、导航、按钮                       |
| 等宽 | JetBrains Mono                              | 时间码、眉标、规格信息（9:16、00:05）  |
| 中文 | 系统宋体（Songti SC / Noto Serif SC）+ 苹方 | 中文标题自动回退为正体宋体，不使用斜体 |

字体文件在 `src/styles/fonts.css` 中自行声明（`font-display: optional`），拉丁子集在 `__root.tsx` 中预加载。

## 3. Logo

`public/logo.svg` / `public/favicon.svg`：深墨色圆角方块，琥珀色半日落在白色海平线上，下方两道逐渐变短的倒影（琥珀到珊瑚色）。
Wordmark 为 `Raindance` 斜体衬线 + 等宽小号上标 `AI`（组件 `Wordmark`，名称取自 `envConfigs.app_name`）。

## 4. 招牌元素：竖屏“成片”

所有展示媒体都是 9:16 竖屏成片（与产品实际输出一致）：

- 圆角 14px，1px 浅色细边 + 8px 墨色衬边 + 深投影，像一张装裱的照片。
- 首页 Hero 成片底部烧录时间码 `00:00 ── 00:05`，琥珀色播放头 5 秒循环。
- “制作流程”用一条海平线串起三步，太阳逐步落下，第三步半没入海面。

## 5. 形状、间距与动效

- 圆角：基础 `--radius: 0.375rem`；面板 18px；成片 14px；按钮全圆角胶囊。
- 区块上下留白 120 到 130px（移动端 84 到 96px）。
- 动效只有四种：Hero 成片缓慢推镜、播放头、成片入场上浮、悬停时画面放大 3.5%。全部遵守 `prefers-reduced-motion`。

## 6. 文案语气

具体、平静、有画面感。不使用 “Elevate / Seamless / Unleash” 之类空泛词，不用破折号。

## 7. 素材

- `public/imgs/brand/frame-*.jpg`：由现有 Hero 插画与 Mixkit 栈桥视频（见 `docs/research/everygen-assets.md`）裁切调色而成的 9:16 帧。
- 原 Hero 插画分辨率仅 1024×576，裁切后清晰度有限。拿到真实生成样片后应优先替换这三张帧。
