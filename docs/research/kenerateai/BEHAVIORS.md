# Kenerate AI homepage reference — interaction notes

Captured with browser automation on 2026-10-04.

| Element                 | Interaction model           | Observed behavior                                                                                                                                                                                                                        |
| ----------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Announcement strip      | Time-driven + click         | Multiple announcement dots; text/CTA cycles automatically. Prev/next and close controls on desktop; condensed strip on mobile.                                                                                                           |
| Header                  | Fixed                       | Remains at viewport top when scrolling. Create/Tools are menu buttons; nav links jump to sections or routes. Search opens a command-search overlay. Mobile has a menu button opening a dialog drawer with Create, Tools and More groups. |
| Hero headline           | Time-driven                 | Noun cycles among creative media; transition uses blurred/sliding typography.                                                                                                                                                            |
| Hero Studio             | Click-driven                | Five tabs (Image, Video, Music, Voice, 3D). Selecting a tab changes the active pill, input's accessible label/suggestions and Generate destination.                                                                                      |
| Prompt suggestion pills | Click-driven                | Populate prompt text. “Surprise me” chooses a preset prompt.                                                                                                                                                                             |
| Hero work wall          | Time-driven + hover + click | Three staggered columns of media cards drift vertically; hover pauses; cards link to a prefilled creator route. Bottom floating label explains remix behavior.                                                                           |
| Showcase                | Click-driven                | All / Images / Video / 3D / Edits filters change displayed work cards.                                                                                                                                                                   |
| Built for               | Click-driven                | Creators / E-commerce / Marketing / Studios & agencies switches adjacent content.                                                                                                                                                        |
| FAQ                     | Click-driven                | Question rows expand/collapse answers.                                                                                                                                                                                                   |
| Mobile menu             | Click-driven                | Full screen dialog-style drawer; close button, search and categorized route lists.                                                                                                                                                       |
