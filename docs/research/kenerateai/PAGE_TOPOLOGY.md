## Responsive composition

- Desktop: 1152 px content lane, 144 px side margins at 1440 px viewport. Hero uses a left interactive column and a right media wall.
- Mobile: 16 px side gutters at 390 px viewport. Header changes to logo, search, short Start button, and hamburger. Hero stacks copy, studio form, proof row, then a two-column media gallery. H1 is 41.6 px / ~42.4 px; section H2 is 30 px / ~31.8 px.
- Section H2 on desktop is 45.6 px / 48.3 px; hero H1 is 67.2 px / 68.5 px. Large bold headings use Google Sans; body uses Inter.
- Background is mostly white with alternating muted gray bands. Hero has a pale blue diffuse glow and a subtle tiny-dot texture. Cards and pills use large rounded corners.
